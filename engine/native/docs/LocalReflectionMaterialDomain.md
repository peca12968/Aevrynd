# 局部反射的接收材質範圍

這項開發中能力讓局部反射只作用於指定材質。河面可以接收周圍場景的反射，同時保留人物、建物與地形原本的環境照明。預設仍為 `All`，既有呼叫不變。

```cpp
const auto environment = engine.ReflectionProbeCaptureEnvironment3D(capture);
if (!engine.SetLocalReflectionProbeMaterialMask3D(
        environment, Aevrynd::LocalReflectionMaterialMask3D::Water)) {
    // 由呼叫端處理尚未就緒、已銷毀或無效的環境擁有者。
}
```

遮罩包含一般表面 `Surface`、水面 `Water`、植被 `Foliage`、地形 `Terrain`，以及全部 `All`、不接收 `None`。它只參與局部探針選擇，不更動全域環境照明。多個探針共用同一個環境 handle 時，也共用接收範圍。銷毀環境會一併移除設定；重新捕捉產生新 handle 時，呼叫端需重新指定。

靜態與蒙皮物件都按實際 `MaterialClass3D` 篩選，再沿用既有的空間、優先序與體積規則。遮罩也加入靜態提交快取的識別。無效遮罩、未知或已銷毀的環境不接受設定。沒有擴張既有探針、繪製清單、引擎或 GPU 資料結構；新增狀態只位於 Renderer 的私有 resident 環境紀錄。

## 已驗證範圍

- 新增 CPU 測試保留原選擇規則，檢查材質組合、空間外、空遮罩、無效資料及較低優先探針的回退。
- 新增 GPU 測試使用真實六面場景捕捉、靜態與蒙皮網格、完整線性 HDR 讀回。全部接收的對照確實改變非水面；改為只接收水面後，非水面區域的 HDR 位元組保持一致，水面區域確實改變。恢復原設定後，完整 HDR 回到同一結果。
- 此 GPU 測試要求實際啟用 GPU 驗證（GBV），檢查已執行與零錯誤、零警告，並驗證未知／無效／銷毀擁有者及資源回收。CTest 為每次執行建立新的輸出位置，不覆蓋舊證據。
- 原有局部反射視覺測試與六面捕捉測試未修改，使用現行 Renderer 物件重新執行並通過。
- 目前遊戲候選完成兩次實機操作與存讀檔測試，並保留完整畫面。河面候選尚未正式採用，不能據此宣稱整體寫實度、穩定版本或視覺分數提升。

這輪為可追溯的增量驗證：現行 Renderer 與 DDS 物件、目前遊戲來源，加上已逐檔核對的引擎封存餘項。不是完整 fresh ALL_BUILD，也不是完整遊戲的 GBV、連續接觸或隔離效能驗收。正式發布仍須補齊相應驗收。
