## 執行

建置 `Mistwatch` target，執行輸出目錄的 `Aevrynd-Mistwatch.exe`。

- Enter：開始；Esc：暫停／繼續。
- WASD：移動；Shift：跑步；Space：跳躍；Ctrl：蹲下。
- 滑鼠左鍵拖曳：環繞鏡頭；滾輪：縮放；左右方向鍵亦可環繞。
- E：拾取、修橋、點亮信標。
- 發電機旁按 1／2／3 切換迴路；依面板提示點亮三盞燈後按 E 送電。
- Q：依移動方向短衝閃避；無方向時向鏡頭後方退避。只能在地面站姿起動，冷卻 1.2 秒；沒有免傷或穿牆。
- F：守衛恢復期間接近反擊，每個恢復窗口限一次；蓄力時離開橙色預警圈。
- 死亡後 R：回到檢查點；通關後 R：新一輪；F5／F9：存檔／讀檔，死亡時仍可讀檔。

流程：取得三個補給箱與棚內工具／兩組木料 → 修復跨谷橋 → 擊敗守衛 → 北側巡林小屋讀紀錄 → 西側工棚解鎖取得保險絲 → 東側發電機恢復供電 → 點亮救援信標。
存檔位於 `%LOCALAPPDATA%/Aevrynd/Mistwatch/save.txt`。
